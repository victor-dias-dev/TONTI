# Security

Please report a vulnerability through [private vulnerability reporting](https://github.com/victor-dias-dev/TONTI/security/advisories/new) on this repository.

Do not open a public issue for a security problem. A public issue exposes the people who run their finances on Tonti before a fix exists.

Include the affected area, what an attacker can do, and the steps to reproduce. We will acknowledge the report and work on a fix before any public disclosure.
